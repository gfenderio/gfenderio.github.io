# assets

Images used on the portfolio.

## Rules for work screenshots (Kyou)

- Every screen runs on made-up data from a local mock. No real customer,
  order, price, SKU or warehouse code may appear.
- No internal app names, logos or menus. Crop them out before use
  (`label-sheet.jpg` is cropped from `label-preview.jpg` for this reason).
- When in doubt, leave the screenshot out and describe the work in words.
